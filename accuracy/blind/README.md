# Blind test

`predictions_dubai_c1.csv` holds the Dubai profile's times for 1 Dec 2026 – 30 Jun 2027, generated by the app's engine on
4 November 2026 (SHA-256 `be4e2ab2352b7be6dc8cf5fe8e27ecc87a09bc0489d55974f234d10b0e202abc`). It must never be edited.

Every month the workflow `.github/workflows/iacad-monthly.yml` makes one request to IACAD's public prayer-times feed,
stores the month under `official/`, and rewrites `REPORT.md` with the score and every difference.
